# charsnap-extensions
Please PR your extensions into this for approval! They will live on CharSnap in an extensions place that makes sense - it must be fully compatible and fully documented in how they are used with a quickstart so I can deploy it easily.

# Requirements
- Code must run and build without needing debugging
- Code must follow the rules of CharSnap: https://charsnap.gitbook.io/charsnap/basics-for-everyone/rules
- Code must be an independently runnable - obviously packages to be installed are fine but no reliance on external software other than a browser.
- Code MUST be written in Node.js, pure HTML/CSS/JS, or at least JS/TS-based as we are dealing with browsers here.
